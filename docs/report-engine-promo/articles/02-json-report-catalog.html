中国式复杂报表的难点，不在“画表格”，而在“语义”。同一份数据，要按地区纵向分片、按产品横向展开；一个事实可以同时属于省、重点地区和“其中”行；排名、占比、同比要随扩展后的格子动态计算。这些能力，用一句 SQL 或一个模板语言都很难覆盖。

我们把它们收敛成一份 JSON 定义，并用 20+ 份可运行样例逐一钉住。下面按八类能力展开。

一、多源关联分片：纵向、横向与整片复制

同一张表里，往往有“几个互不相干的小表”：上面是地区汇总，下面是人员汇总，右侧还要按产品类别动态展开。引擎把这类结构叫分片：每个分片有自己的主格与数据源，彼此独立扩展，又能共享表头与合计口径。

  • 纵向分片销售分析：独立的地区与人员统计纵向排列，产品类别动态横向展开。
  • 横向分片销售分析：地区与销售员横向分片，产品类别纵向扩展，与纵向示例互为转置。
  • 多源关联分片 · 综合示例：两个 SQLite 库、Excel 双工作表、CSV 共同驱动年月×地区城市、人员×产品类别与九张订单主子片，浏览时冻结四行两列。

二、不规则分组：分段、重叠与“其中”行

财务与信贷报表里，分组往往不是简单的 GROUP BY：分段次序由业务给定，边界值要落到指定的段，一个事实还可以同时出现在多个分组里。

  • 按段不完全分组：分段次序来自 Excel，而不是价格排序；包含 20、50、80、100、150 的边界记录，以及被排除的负价格。
  • 重叠分组贷款分析：一个事实可出现在省级、其中行与重点地区中，同时支持多重原因归因；去重后的不良余额仍能对上原始口径。

“其中行”不是视觉缩进，而是集合语义：它既参与分组，又不能被重复加总。

三、自由格间运算：报表不是“填数”，是“算格”

扩展之后，每个格子都有了“结果实例”。公式可以按实例访问上一期、去年同季、上次累计，也可以在块与块之间引用。这类能力是 Excel 公式的“报表版”：

  • 同比环比与累计：按结果实例访问上一期、去年同季与上次累计，覆盖跨年、缺基期与零基数。
  • 动态格间排名与前三名：新增业务会自动新增金额与排名两列，排名、前三名金额及占比均由格间公式计算。
  • 复杂格间计算 · 质量损失分析：同一份产品清单纵向堆成三块（正常卡损失 / 返工退货损失 / 入库金额），累计行用块级格间引用把前两块相加，损失率再除以第三块合计。

四、交叉表合并：合并几行，由数据决定

交叉表里，“大区”“门店”这类维度需要按相邻等值纵向合并；但合并几行不能在设计期写死，必须随数据变化。另一类需求是明细表的同值合并（mergeSame）：相邻等值并成一格，交替值一格都不并。

  • 交叉表动态合并格：大区、门店两级分组按相邻等值纵向合并；月份列因 1 月 / 2 月交替出现而不合并。
  • 明细同值合并：月份列开启纵向同值合并，1 月跨 2 行、2 月跨 2 行；品类列空调 / 冰箱交替，一格都不并。

五、混合数据源：Excel、CSV 与两个数据库同表关联

真实项目里，数据很少只在一个库里。引擎允许一张报表同时挂四份独立来源：Excel、CSV、两个数据库，按业务键关联；数据库连接只在执行端使用，结果页无需再访问数据库。

Excel / CSV / 双数据库联合报表就是这样一个例子：组织库给负责人、经营库给分区域收入、Excel 给预算、CSV 给小数与引号，最后算出跨源净收入与毛利。

六、统计图与图形：图和表共用一套数据

报表不只有网格。销售看板把柱状、饼图、双系列折线与柱线组合四张图排在一页，分别绑定地区、品类、月度三个独立数据集；项目排期用甘特图、状态时间线与里程碑共用一份任务数据；ECharts 既支持 option 模板的参数注入，也支持在 sandbox iframe 里执行真正的 JS formatter 回调。

七、条码与标签：从数据到可裁切的标签纸

条形码错位显示用 barcode() 逐行生成 Code 128B 条码（PNG data URI），奇数号标签条码在左、偶数号在右，错开排版便于裁切。它说明引擎不仅能“算”，还能把结果落到打印交付物上。

八、典型业务报表：财务报表也能一份定义跑通

  • 利润表：营业收入到净利润逐级计算，本期 / 上期两列同口径汇总，变动率按行计算，三级缩进体现科目层级。
  • 资产负债表：一张 A4 并排两栏，左资产、右负债和所有者权益，底部给出平衡校验差额（本例为 0）。
  • 员工工资表：部门纵向分组自动合并，员工逐行展开，应发与实发是逐行计算列，合计行由明细汇总。
  • 库存进销存台账：期初 + 入库 − 出库 = 期末，期末是同行字段的表达式结果。
  • 资金日记账：每行余额 = 上一行余额 + 借方 − 贷方，首行加期初余额，期初值放在宏里。
  • 销售发货单：抬头、多行明细、金额合计、13% 增值税、价税合计与签收栏，一张纸可直接打印交付。

样例即测试

这 20+ 份样例不是“截图集”，而是可执行的回归夹具：每份都有模板、数据、期望取值与运行校验。引擎改动后，样例必须全部重新跑通。对使用者来说，它们是可以直接打开、修改、另存为起点的工作模板；对引擎来说，它们是行为契约。
