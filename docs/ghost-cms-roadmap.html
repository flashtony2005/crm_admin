④ 关键决策与风险

图片存储：当前为内联 base64（零后端、已压缩 1280px/JPEG0.78）。多图/大图建议 P2 增加 POST /api/upload（multipart，权限 content.media.upload 已存在）+ 静态服务 /uploads/*，正文引用 URL。
公开阅读 XSS：/m 详情用 dangerouslySetInnerHTML 渲染 content。当前仅可信编辑者写入，风险低；公开站点（P3）上线前必须加 DOMPurify 清洗。
Turso 切换：设 TURSO_URL + TURSO_AUTH_TOKEN 即自动切云库；本地迁移脚本对 cms.db/cms_live.db 已执行，云库需在 Turso CLI 执行同一迁移。
编译限制：本沙箱无法 cargo build（系统级拦截 .cargo-build-lock）。P2 后端改动需你本地编译；前端改动 HMR 即时生效，可先行验收。
